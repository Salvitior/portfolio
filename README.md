# Portfolio de Salva Carbonell

## Descripción

Este repositorio contiene mi portfolio personal, creado como parte de las actividades del Tema 2 de HTML.

En él presento información sobre mí, mis conocimientos, mis objetivos y las herramientas que utilizo para desarrollar páginas web.

## Contenido

- `index.html`: mi ficha personal.
- `entorno.html`: explicación de mi entorno de trabajo y del funcionamiento de una página web.
- `img/`: carpeta para guardar las imágenes del proyecto.

## Tecnologías y herramientas

- HTML5
- Visual Studio Code
- Live Server
- Git
- GitHub
