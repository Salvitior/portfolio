Mi entorno de trabajo

Qué ocurre cuando escribo una URL

Cuando escribo una dirección web en el navegador, este busca el servidor donde está guardada la página. Para encontrarlo, utiliza el sistema DNS, que traduce el nombre del dominio a una dirección IP.

Después, el navegador se conecta al servidor y le solicita los archivos de la página web mediante HTTP o HTTPS. El servidor responde enviando los archivos necesarios y el navegador interpreta el HTML para mostrar la página en la pantalla.

Herramientas que utilizo

  • Visual Studio Code: lo utilizo para escribir y editar el código de mis páginas web.
  • Live Server: permite abrir la página en el navegador y ver los cambios al guardar.
  • Git: sirve para guardar versiones del proyecto y controlar los cambios.
  • GitHub: permite almacenar repositorios en Internet y compartir los proyectos.
  • Extensiones: añaden funciones a Visual Studio Code para facilitar el trabajo.

Estructura de carpetas de mi portfolio

He organizado mi proyecto en una carpeta principal llamada portfolio. Dentro están las cuatro páginas HTML, el archivo README, una carpeta para las imágenes (con las capturas de mis proyectos) y otra para documentos descargables.
